# Premium Clean — site estático

Arquivos prontos para GitHub Pages. Envie o conteúdo desta pasta para a raiz do repositório e, em **Settings → Pages**, escolha **Deploy from a branch**, branch `main`, pasta `/ (root)`.

## Antes de divulgar

- Confirme os três números no bloco de experiência; estão marcados como ilustrativos.
- Substitua os depoimentos de exemplo por avaliações reais com autorização, se desejado.
- Substitua os dois painéis de vídeo por vídeos reais quando disponíveis.
- A imagem principal é uma imagem gerada para a prévia, não uma foto da equipe.
- Confira a abrangência e eventuais condições de deslocamento.
- O WhatsApp já aponta para `+55 51 98407-9462` com mensagens por serviço.

Site feito em HTML, CSS e JavaScript, sem dependências e sem build.
